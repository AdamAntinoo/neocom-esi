# neocom-esi

Node package of EVE Online ESI classes and tools. The first contents are the Character API DTOs generated by openapi-generator.

```bash
npm install
npm test
```

## Version and publish

Versions come from GitVersion in continuous deployment mode (`GitVersion.yml`). The version-source tag is `v0.1.0`. On `main`, each later commit increments the minor version.

```bash
npm run version:sync
npm run distribute
npm publish
```

## Regenerate the Character API

The OpenAPI document is `openapi/eve-online-character-api-openapi.yml` (the published Character API, declared as OpenAPI 3.0.3 so openapi-generator 7.6 can read it).

```bash
openapi-generator generate \
  -i openapi/eve-online-character-api-openapi.yml \
  -g typescript-fetch \
  -o src/esi-api/characters \
  --additional-properties=supportsES6=true,npmName=neocom-esi,typescriptThreePlus=true,modelPropertyNaming=original
```
